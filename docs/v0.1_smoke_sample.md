# v0.1 smoke sample

```powershell
$env:PYTHONPATH = (Resolve-Path .\src).Path
$fixture = (Resolve-Path .\tests\fixtures\vc6_project).Path
$out = Join-Path $env:TEMP 'unitTestRunner-smoke\Control_Update'

py -m unit_test_runner --json analyze-function `
  --workspace $fixture --dsw "$fixture\Product.dsw" `
  --source 'src\control.c' --function Control_Update `
  --configuration 'Control - Win32 Debug' --project Control `
  --out $out --phase harness

py -m unit_test_runner --json get-test-input-form --workspace $out
$form = Get-Content (Join-Path $out 'reports\test_input_form.json') -Raw |
  ConvertFrom-Json

# promotion_eligibleな代表ケースを1件選び、editableな全項目を確認した
# changes.jsonを作成してから適用します。
py -m unit_test_runner --json apply-test-input-form `
  --workspace $out --input .\changes.json `
  --expected-revision $form.revision

# current TestSpecを変更せず、確認済み入力から実行用ハーネスを再生成します。
py -m unit_test_runner --json analyze-function `
  --workspace $fixture --dsw "$fixture\Product.dsw" `
  --source 'src\control.c' --function Control_Update `
  --configuration 'Control - Win32 Debug' --project Control `
  --out $out --phase harness

py -m unit_test_runner --json finalize-dossier --workspace $out

$spec = Join-Path $out 'reports\test_spec.json'
$sha = (Get-FileHash $spec -Algorithm SHA256).Hash.ToLowerInvariant()
py -m unit_test_runner --json review-set `
  --workspace $out --artifact-kind test_spec --artifact-sha256 $sha `
  --decision approved --reviewer $env:USERNAME

py -m unit_test_runner --json build-probe --workspace $out --dry-run
py -m unit_test_runner --json run-tests --workspace $out --all --plan
```

確認事項:

- JSON responseがexact 5-field CLI envelope
- `reports/function_dossier.json` と `reports/test_spec.json` がschema 1.0.0
- 両artifactの5-field subjectが一致
- 代表ケース1件がTestSpecの `test_cases` に昇格し、生成Cにreview placeholderが残らない
- `review_record.json` がcurrent TestSpec SHAを参照
- `build_probe_report.json` がpublic artifactとしてstrict-valid
- planはbinaryをspawnせず `planned`
- fixture source treeの `git diff` が変化しない

実build/runはhost toolchainとreviewed fixtureが利用可能な場合だけ行います。

```powershell
py -m unit_test_runner --json build-probe --workspace $out --run
py -m unit_test_runner --json run-tests --workspace $out --all --run
```
